# MG3
## Devlog
1. I think the default values for floats, ints, bools, and strings are 0 for each.
2. The update method, which is a built-in method by unity, is automatically called once per frame while the script is enabled and does not need to be called through code. 
3. The TimerText uses the timer by calling a start method which contains code that begins the timer. Then in the update method, if the timer is finished, the result will be a game over text.
